# TC1031-Proyecto

## Slime Rancher
Slime Rancher es un juego Single Player cuya dinámica principal es un simulador de granja.
En tu granja tienes Slimes, criaturas alienígenas infinitamente felices cuyos desechos (plorts)
son útiles para los humanos.
Tu función como granjero es recolectar plorts y venderlos de regreso a la tierra.

## Funcionalidad
Este proyecto busca ser una herramienta que facilite la operación del juego.
Podrás administrar las diferentes áreas de tu rancho, los corrales que cada una contiene
y los slimes de cada corral, pudiendo estimar el alimento requerido para cada corral y área
así como una ganancia estimada según el mercado de plors
